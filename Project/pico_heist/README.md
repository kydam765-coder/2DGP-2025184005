# 피코의 캠핑장 습격 (Pico's Camp Heist)

인간으로 변장한 유인원 **피코**가 세 개의 캠핑장을 돌며, 캠핑객의 시선을 피해
음식 15개를 훔치고, 그중 **진짜 음식 3개**를 모으는 2D 잠입 액션. Python + pico2d, 외부 이미지 없이 도형으로만 만든 그래픽.

> 2D 게임 프로그래밍 · 2025184005 김예닮
> 2차 발표(2주차) 기준 빌드 — **1주차 기본 시스템 + 2주차 맵 구성 완료, 3주차 게임 흐름 일부 선행**

## 실행

```bash
pip install pico2d
python main.py
```

- Python 3.12 / pico2d 1280×720 창
- 실행 파일: `main.py`
- 에셋은 `assets/`에 이미 생성되어 있습니다. 재생성은 아래 참고.

## 조작

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 (발소리 작음) · 낚싯배 조종 |
| **Shift** | 달리기 (빠르지만 발소리가 크다) |
| E | 음식 줍기 / 텐트 안으로 · 밖으로 / **출구 게이트에서 다음 맵·완료** / **호숫가 배 위에서 홀드 → 초록 구간에서 떼어 낚시** |
| **Q** | 부두에서 낚싯배 타기 · 호숫가 아래 끝에서 2번 맵으로 복귀 · 원래 부두에서 하선 |
| **X** | 수풀 안에서 앉기 / 일어나기 (수풀 밖에서는 무시) |
| R | 처음부터 다시 시작 |
| ESC | 종료 |

## 규칙

- 맵마다 음식 5개, 총 **15개**. 1번 맵은 **야외 4개 + 텐트 안 1개**, 2번 맵은 **야외 5개(생선은 낚시로 획득)**, 3번 맵은 **야외 5개**.
- **야외에서 카운트되는 음식은 맵마다 최대 2개다.** 1번 맵은 야외 4개 중 2개, 2번 맵은 야외 4개(생선 제외) 중 2개, 3번 맵은 야외 5개 중 3개가 썩는다.
- **1번 맵은 야외만 다 먹으면 텐트 안 마시멜로가 남아 클리어되지 않는다.** **2번 맵은 텐트가 장식용이라, 부두에서 Q로 낚싯배를 타고 호숫가 낚시 맵으로 가서 생선을 낚아야 한다.**
- **맵의 5번째(마지막) 음식이 ‘진짜 음식’이다.** 숲속 마시멜로(텐트) · 호숫가 생선(낚시) · 야간 축제 수프(야외), 총 **3개**. 절대 썩지 않으며 **이걸 얻지 않으면 맵이 클리어되지 않는다.**
- 전체 썩은 음식은 **7개(2 + 2 + 3)**다. 썩은 음식을 주우면 경고만 뜨고 **수집 카운트에는 포함되지 않는다.** 안 주워도 맵 클리어가 가능하다.
- 한 맵의 **정상 음식 + 마지막 진짜 음식**을 모아도 즉시 넘어가지 않는다. 대신 **출구가 열리고**, 피코가 **길 표지를 따라 게이트까지 직접 걸어가 E를 눌러야** 다음 캠핑장으로 이동한다.
- 캠핑객이 **보거나 듣거나** 하면 **감지도**가 차오른다. 100%가 되면 **추격**이 시작된다.
- 추격 중 따라잡히면 게임 오버. 시야에서 벗어나 따돌리면 캠핑객은 **원래 순찰 자리로 돌아간다**.
- **수풀**에 들어가면 멀리서는 보이지 않고 발소리도 줄어든다. 맵마다 5~7개.
- 수풀 안에서 **X**를 누르면 **앉는다.** 머리만 빼꼼 내밀고, 움직이지 않아 발소리도 나지 않는다.
- 앉아 있는 동안에는 **감지 반경 안(근거리·원거리)에 있어도 눈치채지 못한다.** 자는 사람도, 추격 중인 사람도 놓친다. 수풀을 나오면 자동으로 일어난다.
- **진짜 음식 3개(맵마다 마지막 음식 1개)를 모두 모으면 마지막 출구가 열린다.** 게이트까지 걸어가 **E**를 눌러야 최종 클리어. R로 즉시 재시작.
- 상단 HUD는 **15칸을 그대로 유지**해 어떤 음식을 모았는지 보여준다. 별(★)이 붙은 3칸이 진짜 음식이고, 왼쪽 위에 **“남은 음식: N개”**(현재 맵 기준 5→0)와 **“진짜 음식: N/3”**이 함께 표시된다.
- 맵이 넘어가면서 시간이 흐른다: **숲속 = 한낮 → 호숫가 = 해 질 녘 → 야간 축제 = 밤**
- **호숫가 낚시**: 부두 끝에서 **Q**를 누르면 낚싯배에 탄다. **WASD / 방향키로 배를 직접 조종**하며(자동 항해 없음), **물 영역(y 468~720) 안에서만** 움직인다. 화면 아래 왼쪽·오른쪽 끝과 아래끝까지 이동할 수 있고, 물 아래쪽 끝의 **‘호숫가 이동’ 표지**에 닿으면 **새로운 호숫가 낚시 맵**(`bg_lake_open.png`)으로 전환된다. 낚시 맵에서도 배를 조종해 화면 네 끝까지 갈 수 있다. **E를 1.5초 홀드**하면 게이지가 차고, 움직이는 **초록 구간이 가운데 낚시 바늘에 들어온 순간 E를 떼면** 물고기가 튀어 오르며 소음이 퍼진다. 구간 밖에서 떼거나 너무 오래 잡고 있으면 도망친다. 낚시 맵에서는 **여기서 내리지 않고**, 아래쪽 끝의 **‘부두로 이동’ 안내**를 따라 배를 몰고 **Q**를 누르면 **2번 맵의 원래 부두로 돌아온다.** 돌아온 뒤에도 **배에 탄 상태**이며, **원래 부두에 배가 매어져 있을 때만 ‘배에서 내리기’ 문구가 뜨고 Q로 하선**한다. 부두를 떠나 있으면 Q를 눌러도 내리지 않는다. 하선 후 배는 원래 부두 자리에 그대로 남는다.

## 3개 맵 (+ 텐트 안, 호숫가 낚시 맵)

| # | 맵 | 시간 | 음식 (야외 + 텐트) | 캠핑객 | 수풀 |
|---|---|---|---|---|---|
| 1 | 숲속 캠핑장 | 한낮 | 스튜 · 소시지 · 사과 · 치즈 **+ 마시멜로** | 2명 (순찰) | 7 |
| 2 | 호숫가 캠핑장 | 해 질 녘 | 옥수수 · 샌드위치 · 빵 · 달걀 + **생선(낚시)** | 3명 (순찰 2, 호숫가 낚시 1) | 5 |
| 3 | 야간 축제 캠핑장 | 밤 | 치킨 · 케이크 · 소다 · 베리 · 수프 | 5명 (순찰 3, 감시 1, 배회 1) | 6 |

- **1번 맵에만 텐트 안** 서브 맵이 있다. 텐트 앞 출입구(반짝이는 표시)에서 **E**로 들어가고, 안쪽 출입구에서 다시 **E**로 나온다. 2번 맵의 텐트는 장식이다.
- 2번 맵에는 **부두 위에 서 있는 사람이 없다.** 대신 호숫가 언덕에 **앉아서 낚시하는 캠핑객**이 물을 바라보며 앉아 있다(낚싯줄과 물결 연출 포함).
- 텐트 안에는 **자는 사람**이 있다. 시야는 없지만 **가까이 가면 감지도가 아주 급격하게 오른다**.
- 텐트 안에는 테이블·쿨러·크레이트 짐더미까지 **소품 11개**가 있어 문에서 음식까지 동선이 한 번씩 꺾인다. 테이블은 추격 시야를 끊는 유일한 엄폐물이다. (자는 사람은 소리를 듣지 않으므로 이 소품들은 감지 수치를 낮추지 않고, 동선만 늘린다.)
- 텐트 안에서 쫓기면 출입구로 도망쳐 나올 수 있다 (나가는 순간 추격 종료).
- 마지막 음식(=진짜 음식)이 텐트 안에 있으면, **밖으로 나오는 순간 출구가 열린다.** 게이트까지 걸어가 E를 눌러야 다음 맵으로 간다.
- **2번 맵 호숫가 낚시 맵**: 나무 배 위에서만 움직인다. E 홀드 게이지가 1.5초면 가득 차고, 초록 구간 타이밍에 E를 떼면 물고기가 떠오르는 연출과 소음(26)이 발생한다. 빗나가면 도망친다. 잡은 생선은 HUD 15칸의 ★ 슬롯에 들어간다.

## 감지 시스템

| 조건 | 값 |
|---|---|
| 근거리 (180px 이내) | 기본 초당 +38%, **붙을수록 최대 +103%** 까지 가속 |
| 원거리 (370px 이내 · 시야 콘 55° · 엄폐물 차단 없음) | 초당 +10.5 ~ +19.5% |
| 걷기 발소리 (110px 이내로 들림) | 초당 +9% |
| 달리기 발소리 (270px 이내로 들림) | 초당 +21% |
| **자는 사람 근접 (260px 이내)** | 초당 +46%, **바짝 붙으면 최대 +138%** |
| 시야·소리에서 벗어남 | 초당 −26% |
| 음식 획득 직후 | +6% (한 번) |

- **가까울수록 더 급격하게** 오른다: 근거리 안에서는 거리에 따라 상승률이 커지고, 자는 사람은 그보다 더 가파르다.
- 시야 콘은 캠핑객의 진행 방향을 따라가며, 순찰 중에는 좌우로 살핀다.
- **나무 · 텐트 · 부스 · 테이블**은 엄폐물이다. 그 뒤에 있으면 멀리서는 보이지 않는다.
- **수풀**은 걸어 들어갈 수 있는 은신처다. 잎 안에 있으면 원거리 시야 판정이 차단되고 HUD에 “은신 중”이 뜬다.
- 수풀에서 **X**로 앉으면 HUD에 “수풀 앉기”가 뜨고, 머리만 보인다. 이때는 **근거리(180px)도 감지되지 않고**, 자는 사람(260px)·발소리·추격 시야까지 전부 무시된다. 게이지는 내려가고 추격자는 1.7초 뒤 포기한다.
- 서 있는 은신은 원거리만 차단되지만, **앉은 은신은 근거리까지 차단**한다 — 숨는 것만으로는 안전하지 않았던 규칙이 X로 바뀐다.
- 발소리는 **이동할 때만** 난다. 서 있으면 조용하다. 수풀 안에서는 발소리가 55%로 줄어든다.
- 소리를 들은 캠핑객은 걸음을 멈추고 **소리가 난 쪽으로 고개를 돌린다** → 그대로 있으면 시야에 들어간다.
- 화면에 발소리 반경이 지면 링으로 표시된다 (걷기 작게, 달리기 크게).
- **자는 사람**은 시야 콘과 발소리 판정이 없다. 대신 260px 안에 들어가면 코고는 사람에게서 감지도가 오르고, 깨면 그대로 추격한다.

## 추격

| 단계 | 동작 |
|---|---|
| 시작 | 감지도 100% → 가장 가까운 캠핑객이 추격 (게이지 100 고정) |
| 추격 | 달리기(320px/s)보다 느린 240px/s로 따라온다 → 달리면 거리가 벌어진다 |
| 잡힘 | 46px 안까지 붙으면 게임 오버 |
| 따돌림 | 1.7초 동안 시야에서 벗어나면 포기 → 원래 순찰 자리로 복귀 |
| 복귀 | 복귀 중에는 다시 순찰만 한다. 게이지는 50% 이하로 떨어진다 |

- 추격 중에는 HUD에 **“추격 중”** 배너가 뜬다.
- 수풀에 숨어 시야를 끊는 것이 가장 확실한 따돌리기 방법이다. **수풀에서 X로 앉으면 즉시 시야에서 사라져** 잡히지 않고 추격이 종료된다.

## 파일 구조

```
pico_heist/
├─ main.py          # pico2d 루프, 키 입력 → hold/press
├─ game.py          # 플레이어/캠핑객/소품/음식, 감지·LOS, 추격, 텐트·낚시배·출구, HUD 렌더
├─ maps.py          # 3개 맵 + 텐트 안 1개 + 호숫가 낚시 맵 (소품·음식·캠핑객·출구 길·물/벽 충돌)
├─ art_sprites.py   # 캐릭터·소품·음식·침낭/자는 사람 스프라이트 생성 (PIL)
├─ make_assets.py   # 배경 5종·시야 콘·HUD·텐트/낚시배·출구 게이트/길 표지·인트로/엔딩 오버레이 + 발소리 WAV 생성
└─ assets/          # 생성된 PNG 152개 + WAV 2개
```

- 맵 추가는 `maps.py`의 `MAPS` 리스트에 딕셔너리 하나를 더 넣으면 됩니다.
- 텐트는 `tent` 서브 맵(1번 맵만), 호숫가는 `boat`(부두 탑승점) + `lake`(낚시 전용 서브 맵)로 데이터를 분리했습니다.
- 로직은 맵 데이터와 분리되어 있어, 좌표만 바꿔도 게임이 그대로 동작합니다.

## 상태 흐름

```
intro → playing → (맵 음식 완료) exit_open → 길 표지 따라 이동 → 게이트 E → (다음 맵) intro → playing → …
              ↘ chase (감지 100%) → 따돌림 → return → playing
              ↘ 텐트 안 (E) → playing(tent) → 밖으로 (E) → exit_open
              ↘ 낚싯배 (Q) → sailing → 호숫가 낚시 맵 → 배 위에서 E 홀드 → 초록 구간에서 떼기 → Q로 2번 맵 원래 부두 복귀(배에 탄 상태) → 부두에서 Q 하선(배는 그대로) → exit_open
              ↘ caught (추격 중 따라잡힘)
              ↘ win (마지막 맵 게이트 E — 진짜 음식 3개 / 전체 음식 15개)
```

`caught` / `win` / `intro` 어디서든 **R**로 처음부터 다시 시작합니다.

## 에셋 재생성

```bash
pip install pillow
python make_assets.py
```

- 외부 이미지를 쓰지 않고 PIL 도형으로만 그립니다. (한글 HUD도 이미지로 미리 렌더링)
- 발소리 WAV 2종은 파이썬 `wave`로 합성합니다. 사운드 장치가 없으면 게임은 조용히 실행됩니다.
- 캐릭터는 기존 랩 과제의 피코 스타일(갈색 털 + 호박색 비니 + 초록 재킷)을 유지했습니다.

## 검증

pico2d 창을 띄운 상태에서 로직을 직접 실행하는 자동 검증 209개를 통과했습니다.

- 이동 거리·방향·경계, 근거리/원거리 감지, 게이지 상승·감소
- **거리가 가까울수록 게이지가 더 빨리 오르는지** 비교
- 걷기/달리기 속도 차이, 발소리 반경, 서 있으면 무음, 수풀 안 발소리 감소
- 시야 밖에서 달리면 들리고, 소리를 들은 캠핑객이 고개를 돌림
- 감지 100% → 추격 시작, 추격 중 거리 감소, 따라잡히면 게임 오버
- 따돌리면 추격 종료 → 원래 자리 복귀 → 다시 순찰 (추격 속도 240 확인)
- 시야 콘(뒤·콘 밖), 엄폐물에 의한 시야 차단, 수풀 은신·해제·근거리 예외
- **텐트 출입(E) · 텐트 안 음식 · 자는 사람 근접 급상승 · 텐트 소품 11개 · 텐트에서 출구 개방 지연**
- 음식 프롬프트·획득·획득 소음
- **수풀 앉기(X): 이동 정지 · 근거리·자는 사람·추격 시야 무시 · 추격 포기 · 수풀 이탈 시 자동 일어남**
