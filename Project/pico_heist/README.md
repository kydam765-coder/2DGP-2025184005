# 피코의 캠핑장 습격 (Pico's Camp Heist)

인간으로 변장한 유인원 **피코**가 세 개의 캠핑장을 돌며, 캠핑객의 시선을 피해
음식 9개를 훔치는 2D 잠입 액션. Python + pico2d, 외부 이미지 없이 도형으로만 만든 그래픽.

> 2D 게임 프로그래밍 · 2025184005 김예닮
> 2차 발표(2주차) 기준 빌드 — **1주차 기본 시스템 + 2주차 맵 구성 완료, 3주차 게임 흐름 일부 선행**

## 실행

```bash
pip install pico2d
python main.py
```

- Python 3.12 / pico2d 1280×720 창
- 실행 파일: `main.py`
- 에셋은 `assets/`에 이미 생성되어 있습니다. 재생성은 아래 참고.

## 조작

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 (발소리 작음) |
| **Shift** | 달리기 (빠르지만 발소리가 크다) |
| E | 음식 줍기 / 텐트 안으로 · 밖으로 |
| R | 처음부터 다시 시작 |
| ESC | 종료 |

## 규칙

- 맵마다 음식 3개, 총 9개. **야외에 2개, 텐트 안에 1개**가 숨어 있다 (3번 맵은 야외 3개).
- 한 맵의 음식 3개를 모으면 다음 캠핑장으로 이동한다.
- 캠핑객이 **보거나 듣거나** 하면 **감지도**가 차오른다. 100%가 되면 **추격**이 시작된다.
- 추격 중 따라잡히면 게임 오버. 시야에서 벗어나 따돌리면 캠핑객은 **원래 순찰 자리로 돌아간다**.
- **수풀**에 들어가면 멀리서는 보이지 않고 발소리도 줄어든다. 맵마다 5~7개.
- 9개를 모두 모으면 클리어. R로 즉시 재시작.
- 맵이 넘어가면서 시간이 흐른다: **숲속 = 한낮 → 호숫가 = 해 질 녘 → 야간 축제 = 밤**

## 3개 맵 (+ 텐트 안)

| # | 맵 | 시간 | 음식 (야외 + 텐트) | 캠핑객 | 수풀 |
|---|---|---|---|---|---|
| 1 | 숲속 캠핑장 | 한낮 | 스튜 · 소시지 **+ 마시멜로** | 2명 (순찰) | 7 |
| 2 | 호숫가 캠핑장 | 해 질 녘 | 옥수수 · 생선 **+ 샌드위치** | 3명 (순찰 2, 낚시 1) | 5 |
| 3 | 야간 축제 캠핑장 | 밤 | 치킨 · 케이크 · 소다 | 5명 (순찰 3, 감시 1, 배회 1) | 6 |

- 1·2번 맵에는 **텐트 안** 서브 맵이 있다. 텐트 앞 출입구(반짝이는 표시)에서 **E**로 들어가고, 안쪽 출입구에서 다시 **E**로 나온다.
- 텐트 안에는 **자는 사람**이 있다. 시야는 없지만 **가까이 가면 감지도가 아주 급격하게 오른다**.
- 텐트 안에서 쫓기면 출입구로 도망쳐 나올 수 있다 (나가는 순간 추격 종료).
- 마지막 음식이 텐트 안에 있으면, 밖으로 나오는 순간 맵 클리어가 된다.

## 감지 시스템

| 조건 | 값 |
|---|---|
| 근거리 (180px 이내) | 기본 초당 +38%, **붙을수록 최대 +103%** 까지 가속 |
| 원거리 (370px 이내 · 시야 콘 55° · 엄폐물 차단 없음) | 초당 +10.5 ~ +19.5% |
| 걷기 발소리 (110px 이내로 들림) | 초당 +9% |
| 달리기 발소리 (270px 이내로 들림) | 초당 +21% |
| **자는 사람 근접 (200px 이내)** | 초당 +46%, **바짝 붙으면 최대 +138%** |
| 시야·소리에서 벗어남 | 초당 −26% |
| 음식 획득 직후 | +6% (한 번) |

- **가까울수록 더 급격하게** 오른다: 근거리 안에서는 거리에 따라 상승률이 커지고, 자는 사람은 그보다 더 가파르다.
- 시야 콘은 캠핑객의 진행 방향을 따라가며, 순찰 중에는 좌우로 살핀다.
- **나무 · 텐트 · 부스 · 테이블**은 엄폐물이다. 그 뒤에 있으면 멀리서는 보이지 않는다.
- **수풀**은 걸어 들어갈 수 있는 은신처다. 잎 안에 있으면 원거리 시야 판정이 차단되고 HUD에 “은신 중”이 뜬다.
- 근거리(180px)는 엄폐물·수풀과 관계없이 감지된다 — 숨는 것만으로는 안전하지 않다.
- 발소리는 **이동할 때만** 난다. 서 있으면 조용하다. 수풀 안에서는 발소리가 55%로 줄어든다.
- 소리를 들은 캠핑객은 걸음을 멈추고 **소리가 난 쪽으로 고개를 돌린다** → 그대로 있으면 시야에 들어간다.
- 화면에 발소리 반경이 지면 링으로 표시된다 (걷기 작게, 달리기 크게).
- **자는 사람**은 시야 콘과 발소리 판정이 없다. 대신 200px 안에 들어가면 코고는 사람에게서 감지도가 오르고, 깨면 그대로 추격한다.

## 추격

| 단계 | 동작 |
|---|---|
| 시작 | 감지도 100% → 가장 가까운 캠핑객이 추격 (게이지 100 고정) |
| 추격 | 달리기(320px/s)보다 느린 240px/s로 따라온다 → 달리면 거리가 벌어진다 |
| 잡힘 | 46px 안까지 붙으면 게임 오버 |
| 따돌림 | 1.7초 동안 시야에서 벗어나면 포기 → 원래 순찰 자리로 복귀 |
| 복귀 | 복귀 중에는 다시 순찰만 한다. 게이지는 50% 이하로 떨어진다 |

- 추격 중에는 HUD에 **“추격 중”** 배너가 뜬다.
- 수풀에 숨어 시야를 끊는 것이 가장 확실한 따돌리기 방법이다.

## 파일 구조

```
pico_heist/
├─ main.py          # pico2d 루프, 키 입력 → hold/press
├─ game.py          # 플레이어/캠핑객/소품/음식, 감지·LOS, 추격, 텐트 출입, HUD 렌더
├─ maps.py          # 3개 맵 + 텐트 안 2개 데이터 (소품·음식·캠핑객·물/벽 충돌)
├─ art_sprites.py   # 캐릭터·소품·음식·침낭/자는 사람 스프라이트 생성 (PIL)
├─ make_assets.py   # 배경 4종·시야 콘·HUD·텐트 출입구·인트로/엔딩 오버레이 + 발소리 WAV 생성
└─ assets/          # 생성된 PNG 94개 + WAV 2개
```

- 맵 추가는 `maps.py`의 `MAPS` 리스트에 딕셔너리 하나를 더 넣으면 됩니다.
- 텐트는 별도 맵이 아니라 각 캠핑장의 `tent` 서브 맵입니다. `tent_door`(바깥 출입구) / `tent_exit`(나올 때 위치) 좌표만 있으면 동작합니다.
- 로직은 맵 데이터와 분리되어 있어, 좌표만 바꿔도 게임이 그대로 동작합니다.

## 상태 흐름

```
intro → playing → map_clear → (다음 맵) intro → playing → …
              ↘ chase (감지 100%) → 따돌림 → return → playing
              ↘ 텐트 안 (E) → playing(tent) → 밖으로 (E) → map_clear
              ↘ caught (추격 중 따라잡힘)
              ↘ win (음식 9개)
```

`caught` / `win` / `map_clear` 어디서든 **R**로 처음부터 다시 시작합니다.

## 에셋 재생성

```bash
pip install pillow
python make_assets.py
```

- 외부 이미지를 쓰지 않고 PIL 도형으로만 그립니다. (한글 HUD도 이미지로 미리 렌더링)
- 발소리 WAV 2종은 파이썬 `wave`로 합성합니다. 사운드 장치가 없으면 게임은 조용히 실행됩니다.
- 캐릭터는 기존 랩 과제의 피코 스타일(갈색 털 + 호박색 비니 + 초록 재킷)을 유지했습니다.

## 검증

pico2d 창을 띄운 상태에서 로직을 직접 실행하는 자동 검증 77개를 통과했습니다.

- 이동 거리·방향·경계, 근거리/원거리 감지, 게이지 상승·감소
- **거리가 가까울수록 게이지가 더 빨리 오르는지** 비교
- 걷기/달리기 속도 차이, 발소리 반경, 서 있으면 무음, 수풀 안 발소리 감소
- 시야 밖에서 달리면 들리고, 소리를 들은 캠핑객이 고개를 돌림
- 감지 100% → 추격 시작, 추격 중 거리 감소, 따라잡히면 게임 오버
- 따돌리면 추격 종료 → 원래 자리 복귀 → 다시 순찰 (추격 속도 240 확인)
- 시야 콘(뒤·콘 밖), 엄폐물에 의한 시야 차단, 수풀 은신·해제·근거리 예외
- **텐트 출입(E) · 텐트 안 음식 · 자는 사람 근접 급상승 · 텐트에서 클리어 지연**
- 음식 프롬프트·획득·획득 소음
- 3개 수집(야외 2 + 텐트 1) → 맵 클리어 → 다음 맵 전환, 물 충돌, 9개 수집 → 클리어, R 재시작
- 맵/음식 데이터, 9종 음식 중복 없음, 맵마다 수풀 5개 이상, 텐트 소품 포함 모든 스프라이트 존재
