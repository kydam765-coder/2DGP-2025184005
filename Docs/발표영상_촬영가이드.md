# 2차 발표 영상 촬영 가이드 (1분 30초)

> 대상: `피코의_캠핑장_습격_2차발표.pptx` (2장) + 게임 데모
> 목표 길이: **1:29 ~ 1:30** (1:30 초과는 감점 위험)
> 대본 원문: `Docs/발표_대본_2차_90초.md`

## 0. 촬영 전 준비 (10분)

| 순서 | 할 일 | 확인 |
|---|---|---|
| 1 | 게임 한 판 끝까지 실행 — `cd Project\pico_heist` → `python main.py` | 크래시 없음 |
| 2 | 시작 위치로 되돌리기 — 게임 끄고 다시 실행 (인트로부터) | 인트로 화면 |
| 3 | 파워포인트 열고 **슬라이드 쇼 → 처음부터** (F5) | 1장 전체 화면 |
| 4 | 알림 끄기 — `Win + A` → **집중 지원 / 방해 금지** 켜기 | 카톡·메일 알림 없음 |
| 5 | 마이크 위치 — 입에서 **15~20cm**, 책상 진동 없는 곳 | 녹음 테스트 10초 |
| 6 | 화면 배율 100%, 작업 표시줄 자동 숨김 | 게임 창 가림 없음 |

**창 배치 (중요)**
- PPT는 **전체 화면**(1920×1080), 게임은 **1280×720 창**을 화면 가운데에 크게 놓습니다.
- 게임 창은 크기 조절이 안 되므로, 편집할 때 게임 부분만 잘라 1920×1080으로 키우면 됩니다.
- 발표 중에는 `Alt + Tab`으로 PPT ↔ 게임을 전환합니다. **녹화는 계속 돌아갑니다.**

## 3. 게임 데모 동선 (1:01–1:21)

숫자는 화면 좌표(1280×720). **실제 속도로 플레이**하고, 컷은 편집에서 합니다.

| # | 위치 | 조작 | 화면에 보일 것 |
|---|---|---|---|
| 1 | 시작 (130, 640) | 인트로가 사라질 때까지 대기 | 맵 이름 · 한낮 · 음식 3개 |
| 2 | 마시멜로 (500, 480) | 오른쪽 → 위로 이동 | 걷기 애니메이션 · HUD |
| 3 | 마시멜로 앞 | **E** | E 프롬프트 → 획득 토스트 → 슬롯 1칸 |
| 4 | 캠핑객 순찰선 (420~860, 420) | 일부러 앞으로 진입 | 시야 콘 · 감지도 상승 · 빨간 비네트 |
| 5 | 수풀 (600, 250) | 위로 이동해 수풀 **안으로** | **은신 중** 배지 · 감지도 하락 |
| 6 | 스튜 (640, 300) | 수풀에서 나와 아래로 → **E** | 슬롯 2칸 |
| 7 | 소시지 (1010, 370) | 오른쪽 외곽으로 크게 돌아 → **E** | 슬롯 3칸 → **MAP CLEAR** |

- 맵 클리어 화면은 **1.7초 뒤 자동으로** 호숫가로 넘어갑니다 (키 입력 없음). 인트로도 2.2초 뒤 자동 시작.
- 게임 오버가 나면 **R**을 누르면 숲속 처음부터 다시 시작합니다.
- 이어서 호숫가 1초, 야간 축제는 **2배속**으로 3개 획득 → 클리어 오버레이 2초.
- 축제 맵 음식 위치: 치킨 (250, 308) · 케이크 (790, 468) · 소다 (1000, 560)

### 편집 컷 예시

| 영상 구간 | 화면 | 배속 |
|---|---|---|
| 1:01 – 1:08 | 숲속 이동 → 첫 음식 획득 | 1× |
| 1:08 – 1:13 | 시야 콘 노출 → 감지도 상승 | 1× |
| 1:13 – 1:16 | **수풀 은신** → 감지도 하락 | 1× |
| 1:16 – 1:18 | 맵 클리어 → 호숫가 | 컷 |
| 1:18 – 1:21 | 축제 → 클리어 오버레이 | 2× |

> 20초에 3개 맵을 다 보여줄 수는 없습니다. **전체 플레이를 먼저 녹화해 두고 하이라이트만 쓰는 방식**이 가장 안전합니다.

## 4. 자막 (한 줄씩 넣으면 진행 보고가 명확해짐)

1. `1주차 완료 · 2주차 완료` (슬라이드 2 구간)
2. `감지 = 거리 + 시야 콘 + 엄폐물 + 수풀`
3. `수풀 은신 — 멀리서는 보이지 않는다`
4. `맵 전환 → 9개 수집 → 클리어`

## 5. 편집 (Clipchamp 권장)

1. Clipchamp → **새 동영상** → 녹화 파일 불러오기
2. 앞뒤 잘라내기 → **1:29~1:30**에 맞추기
3. 게임 구간은 **자르기(크롭)** 로 1280×720 부분만 남기고 화면 채우기
4. 자막 4개 넣기 (위 문구)
5. **내보내기: 1080p, 30fps**
6. 내보낸 파일을 **처음부터 끝까지 재생**해서 확인 (가이드 필수 사항)
   - 소리: 말이 또렷한가, 잡음 없는가
   - 화면: 자막이 잘리지 않는가, 게임 키 입력이 보이는가
   - 길이: 1:30 이하인가

## 8. 자주 나는 문제

| 증상 | 해결 |
|---|---|
| 게임 창이 너무 작게 나옴 | 편집에서 크롭 후 확대. 녹화는 1920×1080으로 |
| 목소리가 작음 | 게임 바 마이크 볼륨 확인, 입과 15cm 유지 |
| PPT 넘길 때 커서가 보임 | 슬라이드 쇼에서 마우스 움직이지 않기, 방향키로 넘기기 |
| 감지도가 100%가 되어 게임 오버 | 데모 중 세이프: 수풀에 숨고, 캠핑객 등 뒤로 돌아가기. 실수했으면 R로 재시작 후 그 컷만 다시 |
| 녹화 파일이 4GB 제한 | 게임 바 최대 4GB. 2분 영상은 문제 없음 |
