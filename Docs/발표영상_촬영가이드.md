## 0. 촬영 전 준비 (10분)

| 순서 | 할 일 | 확인 |
|---|---|---|
| 1 | 게임 한 판 끝까지 실행 — `cd Project\pico_heist` → `python main.py` | 크래시 없음 |
| 2 | **텐트 입장 → 자는 사람 → 추격 → 수풀로 따돌리기**를 한 번 연습 | 텐트 안 · 추격 배너 확인 |
| 3 | 시작 위치로 되돌리기 — 게임 끄고 다시 실행 (인트로부터) | 인트로 화면 |
| 4 | 파워포인트 열고 **슬라이드 쇼 → 처음부터** (F5) | 1장 전체 화면 |
| 5 | 알림 끄기 — `Win + A` → **집중 지원 / 방해 금지** 켜기 | 카톡·메일 알림 없음 |
| 6 | 마이크 위치 — 입에서 **15~20cm**, 책상 진동 없는 곳 | 녹음 테스트 10초 |
| 7 | 화면 배율 100%, 작업 표시줄 자동 숨김 | 게임 창 가림 없음 |

**창 배치 (중요)**
- PPT는 **전체 화면**(1920×1080), 게임은 **1280×720 창**을 화면 가운데에 크게 놓습니다.
- 게임 창은 크기 조절이 안 되므로, 편집할 때 게임 부분만 잘라 1920×1080으로 키우면 됩니다.
- 발표 중에는 `Alt + Tab`으로 PPT ↔ 게임을 전환합니다. **녹화는 계속 돌아갑니다.**

## 3. 게임 데모 동선 (1:04–1:22)

숫자는 화면 좌표(1280×720). **실제 속도로 플레이**하고, 컷은 편집에서 합니다.

| # | 위치 | 조작 | 화면에 보일 것 |
|---|---|---|---|
| 1 | 시작 (130, 640) | 인트로가 사라질 때까지 대기 | 맵 이름 · 한낮 · 음식 3개 |
| 2 | 텐트 출입구 (350, 320) | 오른쪽 → 위로 **걷기** | 발소리 링이 **작게** 퍼짐 · **E 텐트 안으로** |
| 3 | 텐트 안 (640, 668) | **E** 로 입장 | 텐트 내부 · HUD “텐트 안” · **자는 사람** |
| 4 | 크레이트 (820, 330) | 자는 사람 반대쪽으로 접근 | 감지도 **급상승** · Zzz |
| 5 | 마시멜로 (820, 286) | **E** | 획득 토스트 · 슬롯 1칸 |
| 6 | 출입구 (640, 678) | **E** 로 밖으로 | 야외 복귀 · 감지도 초기화 |
| 7 | 스튜 (640, 300) | 위로 **걷기** → **E** | 슬롯 2칸 |
| 8 | 오른쪽 통로 (760~900, 620) | **Shift + D** 로 달리기 | 발소리 링이 **크게** · 캠핑객이 고개를 돌림 |
| 9 | 캠핑객 근처를 계속 달리기 | 일부러 노출 | 감지도 100% · **“추격 중”** 배너 |
| 10 | 수풀 (1080, 650) | 추격자를 끌고 달려 수풀에 숨기 | 추격 종료 → 캠핑객이 순찰 자리로 **복귀** |
| 11 | 소시지 (1010, 370) | 마지막 음식 **E** | **MAP CLEAR** 2초 |

- **이번 데모의 핵심은 텐트**입니다. 2~6번에서 “음식이 텐트 안에 있고, 자는 사람에게 붙으면 위험해진다”가 한 번에 보이게 찍으세요.
- 텐트 안에서는 **자는 사람 200px** 안에 들어가면 게이지가 초당 46~138%로 오릅니다. 음식만 챙기고 **바로 출입구로** 나오세요.
- **발소리 대비**도 함께 보여줍니다. 2번(걷기, 작은 링)과 8번(달리기, 큰 링)이 같은 화면에서 비교되도록 찍으세요.
- 8번 이후 바로 잡히지 않도록 **달리면서 수풀 쪽으로** 이동합니다. 추격자는 240px/s, 피코 달리기는 320px/s라 거리가 벌어집니다.
- 추격을 따돌리는 데 최대 9초가 걸릴 수 있으니, **10번은 넉넉히 녹화한 뒤 편집에서 2~3초만** 사용하세요.
- 맵 클리어 화면은 **1.7초 뒤 자동으로** 호숫가로 넘어갑니다 (키 입력 없음). 인트로도 2.2초 뒤 자동 시작.
- 게임 오버가 나면 **R**을 누르면 숲속 처음부터 다시 시작합니다.
- 이어서 호숫가 1초, 야간 축제는 **2배속**으로 3개 획득 → 클리어 오버레이 2초.
- 호숫가 텐트 출입구는 **(300, 320)**, 안쪽 음식은 샌드위치다. 1초만 보여줘도 “맵마다 텐트”가 전달됩니다.
- 축제 맵 음식 위치: 치킨 (250, 308) · 케이크 (790, 468) · 소다 (1000, 560)

### 편집 컷 예시

| 영상 구간 | 화면 | 배속 |

| 1:04 – 1:07 | 텐트 출입구 → **E 입장** · 자는 사람 | 1× |

## 4. 자막 (한 줄씩 넣으면 진행 보고가 명확해짐)

1. `1주차 완료 · 2주차 완료` (슬라이드 2 구간)
2. `감지 = 거리 + 시야 콘 + 엄폐물 + 수풀 + 발소리` (슬라이드 3 구간)
3. `걷기 = 조용히 (110px)` / `Shift 달리기 = 시끄럽게 (270px)`
4. `가까울수록 위험 상승이 빨라진다`
5. `텐트 안 — 자는 사람에게 붙으면 게이지 폭증`
6. `감지 100% → 추격`
7. `따돌리면 순찰 복귀`
8. `맵 전환 → 9개 수집 → 클리어`

## 5. 편집 (Clipchamp 권장)

1. Clipchamp → **새 동영상** → 녹화 파일 불러오기
2. 앞뒤 잘라내기 → **1:29~1:30**에 맞추기
3. 게임 구간은 **자르기(크롭)** 로 1280×720 부분만 남기고 화면 채우기
4. 자막 4개 넣기 (위 문구)
5. **내보내기: 1080p, 30fps**
6. 내보낸 파일을 **처음부터 끝까지 재생**해서 확인 (가이드 필수 사항)
   - 소리: 말이 또렷한가, 잡음 없는가
   - 화면: 자막이 잘리지 않는가, 게임 키 입력이 보이는가
   - 길이: 1:30 이하인가

## 8. 자주 나는 문제

| 증상 | 해결 |
|---|---|
| 게임 창이 너무 작게 나옴 | 편집에서 크롭 후 확대. 녹화는 1920×1080으로 |
| 목소리가 작음 | 게임 바 마이크 볼륨 확인, 입과 15cm 유지 |
| PPT 넘길 때 커서가 보임 | 슬라이드 쇼에서 마우스 움직이지 않기, 방향키로 넘기기 |
| 텐트 안에서 감지도가 확 오름 | **바로 출입구로**. 자는 사람 200px 밖으로 나가면 게이지가 내려갑니다 |
| 감지도가 100%가 되어 **추격**이 시작됨 | 당황하지 말고 **Shift로 달리면서 수풀로**. 추격자(240px/s)는 달리기(320px/s)보다 느립니다. 잡히면 R로 재시작 후 그 컷만 다시 |
| 추격이 안 끝나고 계속 따라옴 | 수풀(760, 660)·(880, 510)·(1080, 650) 중 가까운 곳으로 들어가 시야를 끊으세요. 1.7초면 포기합니다 |
| 텐트 안에서 쫓김 | 출입구(640, 678)로 달려가면 **자동으로 밖으로 나오며 추격 종료** |
| 발소리가 영상에 안 들어감 | 이 PC에 사운드 장치가 없으면 게임이 조용히 실행됩니다. 그때는 자막으로 `걷기 조용 / 달리기 시끄러움`을 표시하세요 |
| 녹화 파일이 4GB 제한 | 게임 바 최대 4GB. 2분 영상은 문제 없음 |
